# Introduction to Simple JavaScript Project

## Objectives

- Create a well-structured HTML5 document.
- Write JavaScript functions to manipulate the DOM.
- Respond to user interactions through dynamic changes.

## Instructions

- Ensure the HTML document includes the necessary DOCTYPE, html, head, and body elements.
- Link the script.js file to the HTML document.

>[!NOTE]
> - The JavaScript should:
>   - Change text content dynamically.
>   - Modify CSS styles via JavaScript.
>   - Add or remove an element when a button is clicked.

## Tasks

- Use at least 5 different HTML elements in the index.html file.
- Ensure semantic correctness in the HTML structure.
